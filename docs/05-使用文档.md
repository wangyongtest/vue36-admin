# 使用文档

## 一、快速开始

### 1.1 获取项目代码

```bash
# 克隆项目
git clone <项目地址>
cd vue36-enterprise-admin

# 安装依赖（必须用pnpm）
pnpm install
```

### 1.2 启动开发环境

```bash
# 普通模式启动
pnpm dev

# 大型项目推荐使用Vite 8.1打包开发模式，启动速度快15倍
pnpm dev:bundled
```

启动成功后浏览器访问 http://localhost:3000

### 1.3 生产构建

```bash
# 类型检查 + 生产构建
pnpm build

# 本地预览生产构建产物
pnpm preview
```

### 1.4 代码检查与测试

```bash
# Oxlint检查 + 自动修复
pnpm lint

# 运行单元测试
pnpm test

# 运行测试并生成覆盖率报告
pnpm test:coverage

# TypeScript类型检查
pnpm typecheck
```

## 三、常见开发场景

### 3.1 新增一个业务页面

以新增"用户管理"列表页为例，遵循DDD分层开发：

#### Step 1: 定义领域实体（领域层）

`src/domain/user/user.entity.ts`
```ts
export interface User {
  id: number
  username: string
  nickname: string
  email: string
  phone: string
  status: number
  createTime: string
}
```

#### Step 2: 定义仓储接口 + 实现（领域层+基础设施层）

```ts
// domain/user/user.repository.ts - 接口定义
export interface UserRepository {
  list(params: UserQuery): Promise<PageResult<User>>
  create(user: UserCreateDTO): Promise<void>
  update(user: UserUpdateDTO): Promise<void>
  delete(id: number): Promise<void>
}

// infrastructure/repositories/user.repository.impl.ts - 实现
import http from '@infra/http'
export class UserRepositoryImpl implements UserRepository {
  list(params: UserQuery) { return http.get('/system/user/list', { params }) }
  create(data: UserCreateDTO) { return http.post('/system/user', data) }
  // ...
}
```

#### Step 3: 编写应用服务（应用层）

`src/application/services/user.service.ts`
```ts
import { UserRepositoryImpl } from '@infra/repositories/user.repository.impl'
const userRepo = new UserRepositoryImpl()

export const userService = {
  getUserList: (params: UserQuery) => userRepo.list(params),
  createUser: async (data: UserCreateDTO) => {
    // 业务规则编排
    return userRepo.create(data)
  },
}
```

#### Step 4: 编写页面组件（表现层）

`src/presentation/views/system/user/index.vue`
```vue
<template>
  <PageContainer title="用户管理">
    <ProTable :columns="columns" :request="userService.getUserList" />
  </PageContainer>
</template>

<script setup lang="ts">
import { userService } from '@application/services/user.service'
import { columns } from './schema'
</script>
```

#### Step 5: 注册路由

在 `src/presentation/router/routes/system.ts` 中添加路由配置。

### 3.2 Vapor Mode 渐进式启用

Vue 3.6 Vapor Mode是按组件渐进启用的，不需要全站切换：

1. **纯展示、大量重复渲染的组件优先开**：表格行、列表项、卡片、标签等性能敏感组件
2. **布局组件、复杂交互表单不要开**：布局组件依赖大量第三方UI组件，VDOM模式兼容性更好
3. **启用方式**：在组件 `<script setup>` 标签上添加 `vapor` 属性

```vue
<!-- 性能敏感的字典标签组件，启用Vapor Mode -->
<script setup lang="ts" vapor>
defineProps<{ label: string; type?: string }>()
</script>

<template>
  <a-tag :color="type">{{ label }}</a-tag>
</template>
```

### 3.3 权限控制使用

#### 路由级权限

在路由meta中配置权限标识：
```ts
{
  path: '/system/user',
  component: () => import('@/views/system/user/index.vue'),
  meta: {
    title: '用户管理',
    permissions: ['system:user:list'],
  },
}
```
路由守卫会自动校验权限，无权限自动跳转403。

#### 按钮级权限

使用v-auth指令：
```vue
<template>
  <!-- 有新增权限才显示按钮 -->
  <a-button type="primary" v-auth="'system:user:add'">新增用户</a-button>

  <!-- 函数式判断 -->
  <a-button v-if="hasPerm('system:user:delete')" danger>删除</a-button>
</template>

<script setup lang="ts">
import { hasPerm } from '@/utils/permission'
</script>
```

### 3.4 日志查看与排查

开发环境所有日志分类输出到控制台：
- **[DEBUG]** 调试信息（开发环境全量）
- **[INFO]** 普通信息（接口请求、性能指标）
- **[WARN]** 警告（慢接口>3s、废弃API）
- **[ERROR]** 错误（组件错误、接口错误、资源加载失败）

生产环境：
- ERROR级别以上日志自动上报到日志服务
- 可以在控制台执行 `logger.getCache()` 查看最近100条本地缓存日志，方便复现问题时排查

## 四、常见问题

### Q1: 启动时报Node版本错误？
A: Vite 8要求Node ≥ 20.19.0或≥22.12.0，请升级Node版本后重新安装依赖。

### Q2: 大型项目启动慢怎么办？
A: 使用 `pnpm dev:bundled` 开启Vite 8.1打包开发模式，10000+组件项目启动速度从分钟级降到秒级。

### Q3: Vue 3.6升级后旧组件报错？
A: Vue 3.6完全兼容3.x代码，无破坏性变更。如果开启了Vapor Mode遇到问题，检查组件是否正确使用了响应式API，移除vapor属性即可回退到VDOM模式。

### Q4: 如何对接后端接口？
A: 修改 `.env.development` 中的 `VITE_API_BASE_URL` 为后端接口地址，接口按RESTful规范开发，响应拦截器会统一处理错误提示。

### Q5: 单元测试覆盖率不达标怎么办？
A: 重点覆盖领域层（100%要求）和工具函数，UI组件测试可以优先覆盖核心交互组件，非交互展示组件可以适当降低覆盖率要求。
