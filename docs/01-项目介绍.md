# Vue 3.6 企业级中台管理系统 - 项目介绍

## 一、项目概述

**Vue 3.6 企业级中台管理系统**是基于 Vue 3.6（Vapor Mode 正式版）、Vite 8.1、TypeScript 7、Ant Design Vue 4.x、Pinia 3 最新技术栈开发的企业级中后台管理解决方案。

项目采用**DDD领域驱动设计**思想进行架构分层，**TDD测试驱动开发**保证代码质量，内置完整的日志体系（项目报错、文件报错、Oxlint规范错误、性能监控、接口请求日志），覆盖企业级系统管理全场景。

## 二、技术特色

### 2.1 核心技术栈

| 技术 | 版本 | 说明 |

| Vue | 3.6.x | Vapor Mode 正式版，响应式底层为 alien-signals，性能提升 1.8 倍 |

| Vitest | 3.x | TDD 单元测试，与 Vite 同构 |

### 2.2 架构特色

- **DDD 领域驱动分层架构**：表现层 → 应用层 → 领域层 → 基础设施层，四层解耦
- **TDD 测试驱动开发**：单元测试覆盖率要求 ≥ 80%，组件测试 + 工具函数测试全覆盖
- **Vapor Mode 渐进式启用**：性能敏感组件启用 Vapor，运行时体积仅 4KB，兼容传统 VDOM 组件
- **完整日志体系**：错误日志、性能日志、接口日志、规范错误日志五大类，全链路追踪
- **多布局一键切换**：左侧/顶部/混合/双栏 4 种布局模式，配置持久化
- **三级权限体系**：路由级 + 按钮级 + 数据级权限，支持前端静态/后端动态双模式
- **系统管理全模块**：用户/角色/菜单/部门/字典/配置/日志/在线用户/租户，开箱即用

## 四、项目优势

1. **版本最新稳定**：所有依赖均为 2026 年 9 月最新稳定版，Vue 3.6 Vapor Mode 生产可用
2. **架构清晰可维护**：DDD 分层设计，模块边界清晰，长期维护成本低
3. **质量保障完善**：TDD 测试驱动，五大日志体系，问题可快速定位
4. **开箱即用**：系统管理 10 大模块全字段设计，直接对接后端即可使用
5. **性能卓越**：Vapor Mode + Vite 8.1 Rolldown，开发和生产性能均为当前最优
6. **最佳实践沉淀**：融合 GitHub Vue 生态 Top5 后台模板（Vben/Pure/Soybean/Antdv Pro/Geeker）精华设计
